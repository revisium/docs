# Examples

Use Revisium examples when you want a copyable project shape instead of only API reference material.

The examples repository covers local standalone runs, Docker Compose, Revisium Cloud, application integrations, and self-hosted infrastructure references.

## Quickstarts

| Example | Use case | Modes |
| --- | --- | --- |
| [Standalone Quickstart](https://github.com/revisium/revisium-examples/tree/master/quickstarts/standalone) | Local development and demos | Standalone |
| [Docker Compose](https://github.com/revisium/revisium-examples/tree/master/quickstarts/docker-compose) | Local service with PostgreSQL | Docker |
| [Docker Compose With S3 And Redis](https://github.com/revisium/revisium-examples/tree/master/quickstarts/docker-compose-s3) | File storage and cache parity | Docker |
| [Revisium Cloud](https://github.com/revisium/revisium-examples/tree/master/quickstarts/cloud) | Managed project, MCP, generated APIs | Cloud |
